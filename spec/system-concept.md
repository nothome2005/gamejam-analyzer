# Концепція системи: Game Jam Analyzer

## 1. Загальне призначення
Інформаційна система систематизації та інтелектуального аналізу даних про ігрові хакатони (джеми), команди розробників, учасників та створені під час заходів ігрові проєкти.

## 2. Зацікавлені сторони (Stakeholders)
- Організатори джемів: моніторинг активності, реєстрація регламенту, підбиття підсумків.
- Учасники та команди: подання робіт, формування профілю розробника, пошук однодумців.
- Члени журі: оцінювання сирцевого коду, відповідності темі та якості проєктів.
- Спільнота / Гравці: тестування створених прототипів, коментування, голосування.

## 3. Базові сутності предметної області
- Jam (Джем): назва, часові рамки, тема, організатор, регламент проведення.
- Participant (Учасник): профіль, спеціалізація (Gameplay Programmer, 2D/3D Artist, Sound Designer).
- Team (Команда): назва, капітан, склад зареєстрованих учасників.
- Submission (Проєкт): надіслана гра. Обов'язково містить зовнішні URL на WebGL-білд (Itch.io / GameJolt), обмеження ваги архіву до 500 МБ, ідентифікатор цільової платформи та перелік використаних сторонніх асетів.
