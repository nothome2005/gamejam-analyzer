# Паспорт кодингового агента

## 1. Загальні відомості
- Назва інструменту: Antigravity / Gemini Code Agent
- Версія: 2.0 (DeepMind Core)
- Клас інструменту: Автономний агентний AI-асистент кодування (Autonomous Agentic Coding Assistant)

## 2. Спосіб доступу до репозиторію
- Прямий доступ до робочої файлової системи через CLI-інструменти та термінальний інтерфейс.
- Можливість виконання системних команд Git (init, checkout, branch, commit, merge, diff).

## 3. Дозволені операції в робочому середовищі
- Читання та семантичний аналіз структури сховища та файлів специфікацій (/spec).
- Генерація та модифікація специфікацій, коду компонентів (/src) та тестів (/tests).
- Ведення журналів взаємодії та оформлення звітів контрольних точок (/logs).
- Формування пропозицій змін та підготовка комітів за конвенцією SDD.

## 4. Модель взаємодії
- Режим Human-in-the-loop: людина здійснює обов'язкову верифікацію змін (через git diff) перед інтеграцією у стабільні гілки. Автоматичне злиття без валідації специфікації заборонено.
